# Architecture Decision Records

Dated records of load-bearing design decisions — including decisions **not** to
build something. An unbuilt design captured honestly here is credibility; the
same idea listed on a capability matrix as if it shipped is the opposite (the
"claimed-but-not-wired" defect this repo has fixed more than once). If a
capability is described in an ADR with status "not built," mnemo does not enforce
it today.
